📖 Diccionario de Términos, Motores y Estrategias

📌 1. Sistemas Operativos Objetivo

🤖 Android (APK / PWA)

Configuración estándar para generar un archivo instalable en Android (.apk/.aab) usando herramientas como Bubblewrap, PWABuilder o Capacitor.

🍎 iOS (Safari WebApp / Offline)

Ajustes específicos para Safari Mobile en iPhone/iPad, activando el modo pantalla completa nativo de iOS, icono en inicio y Service Worker para ejecución sin internet.

🚀 Universal

Genera la lista completa de parámetros soportados globalmente por Android, iOS y navegadores de escritorio al mismo tiempo.

📝 2. Datos Generales de la WebApp

📛 Nombre de la App (`name`)

El nombre completo oficial de tu aplicación web tal como aparecerá en la tienda de aplicaciones o en los instaladores.

🏷 Nombre Corto (`short_name`)

Nombre abreviado que se muestra debajo del icono en la pantalla de inicio de los teléfonos móviles cuando el espacio es reducido.

💬 Descripción (`description`)

Texto explicativo breve que describe la función principal de tu aplicación para navegadores y compiladores.

🚀 Start URL (`start_url`)

La página inicial que se cargará automáticamente cuando el usuario abra la app compilada o el icono instalado (Ejemplo: `./index.html` o `/`).

🌐 Scope / Alcance (`scope`)

Define el conjunto de URLs o directorio al que está restringida la app web. Si el usuario navega fuera de este alcance, se abrirá un navegador normal.

🔢 Versión (`version`)

Número de versión del paquete (ej. `1.0.0`) necesario para gestionar actualizaciones cuando compiles la APK.

🌐 Idioma (`lang`)

Especifica el idioma predeterminado de la aplicación (ej. `es-ES`, `en-US`), permitiendo al navegador aplicar reglas de accesibilidad y traducción.

🎨 3. Apariencia y Comportamiento

📱 Modo de Pantalla (`display`)

Standalone: Oculta la barra del navegador para que parezca una app nativa.
Fullscreen: Oculta también la barra de estado del sistema.
Minimal-UI: Conserva un conjunto básico de controles de navegación.

🔄 Orientación (`orientation`)

Fija si la app debe mantenerse en formato vertical (Portrait), horizontal (Landscape) o adaptarse libremente a la rotación del teléfono (Any).

🎨 Theme Color (`theme_color`)

El color que adoptará la barra de estado superior del sistema operativo y la cabecera del navegador al abrir la app.

🖼 Background Color (`background_color`)

Color de fondo que se muestra mientras se carga la app antes de desplegar el contenido web (Pantalla de carga / Splash Screen).

🖼 Ruta del Icono (`icons`)

Ubicación del archivo PNG de la aplicación (recomendado 512x512 px) configurado con soporte `any maskable` para adaptarse a iconos adaptativos en Android.

⚙️ 4. Estrategias Caché & Service Worker

⚡ Cache First (Carga instantánea)

Busca los recursos primero en la memoria local (caché). Si existen, los entrega de inmediato sin consultar la red. Ideal para assets estáticos y rendimiento offline total.

🌐 Network First (Prioriza red)

Intenta descargar los datos más recientes desde internet. Si el dispositivo no tiene conexión, recurre a la versión almacenada en caché como respaldo.

🔄 Stale-While-Revalidate

Muestra inmediatamente la versión almacenada en caché para dar velocidad instantánea, mientras descarga en segundo plano la versión más reciente para actualizar la siguiente sesión.

🧹 Limpieza Automática de Caché

Borra las versiones antiguas almacenadas en el dispositivo cada vez que detecta e instala un Service Worker con nueva versión o timestamp.

🚀 5. Funciones Avanzadas (UX, Push & CI/CD)

📱 Modal Nativo de Instalación (`beforeinstallprompt`)

Captura el evento nativo del navegador para que puedas activar un botón de "Instalar App" personalizado dentro de tu interfaz web.

🔔 Soporte Web Push & VAPID Key

Habilita los escuchadores `push` y `notificationclick` en el Service Worker, permitiendo enlazar tu clave VAPID pública para recibir notificaciones en segundo plano.

⚙️ CI/CD GitHub Actions Workflow

Genera un archivo `.github/workflows/deploy-pwa.yml` listo para automatizar las pruebas, construcción y despliegue continuo de tu proyecto cada vez que subes cambios a GitHub.

🌐 Metas Open Graph (SEO Social)

Etiquetas estructuradas (`og:title`, `og:description`, `og:image`) para asegurar que al compartir el enlace de tu app en redes sociales se muestren las tarjetas visuales personalizadas.

🔬 Auditoría PWA Express

Módulo de verificación interna que analiza tu configuración en tiempo real comprobando que cumpla con los estándares mínimos para ser instalable y compatible.

⚡ 6. Motores de Compilación Soportados

⚡ Capacitor CLI (Ionic)

El motor nativo moderno preferido para envolver proyectos web en aplicaciones Android e iOS nativas completas, ofreciendo máxima compatibilidad con plugins de hardware.

🤖 Google Bubblewrap CLI

Herramienta oficial de Google que transforma una PWA en un paquete Android Trusted Web Activity (TWA) ligero y de alto rendimiento.

🌐 Microsoft PWABuilder

Plataforma impulsada por Microsoft para empaquetar aplicaciones web progresivas en tiendas de aplicaciones como Google Play Store y Microsoft Store.
